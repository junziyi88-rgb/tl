# Neon 微信连通性测试页设计

## 目标

在现有腾讯云静态托管中增加一个独立页面 `/neon-test.html`，供用户在微信内置浏览器打开，验证中国大陆移动网络能否访问 Neon 的公开 HTTPS 服务。

## 范围

- 不修改塔罗主应用及其路由。
- 不依赖已停用的 PostgreSQL、身份认证或云函数。
- 不创建 Neon 账号、数据库或 API Key。
- 不收集、保存或上传测试者的个人信息。
- 本页面只验证 HTTPS 网络连通性，不宣称已经验证真实 SQL 读写。

## 页面与交互

- 页面加载后自动运行测试，同时提供“重新测试”按钮。
- 测试目标：Neon 官网、Neon 控制台、Neon 区域延迟页面。
- 每个目标发起带随机参数的跨域资源请求，设置明确超时；记录成功、失败和耗时。
- 展示汇总结论：全部可达、部分可达或全部不可达。
- 展示测试时间、浏览器信息和网络类型（仅在浏览器提供时显示）。
- 提供“复制结果”按钮，便于用户把文字结果发回。
- 对不支持相关浏览器 API 的微信版本显示可理解的降级提示。

## 技术方案

- 使用单个原生 HTML 文件，内含少量 CSS 和 JavaScript，不增加项目依赖。
- 文件放入 `public/neon-test.html`，由 Vite 构建原样复制到 `dist/neon-test.html`。
- 使用 `fetch` 的 `no-cors` 模式测试跨域可达性；请求成功只代表网络请求完成，不读取第三方响应内容。
- 每个请求设置 8 秒超时，避免微信页面长时间无反馈。
- 页面视觉保持简洁，适配手机安全区和深色模式。

## 错误处理与结果解释

- 超时、DNS 失败、TLS 失败或请求被拦截统一显示为“不可达/超时”。
- 页面明确注明：测试结果受当前运营商、Wi-Fi、VPN 和微信版本影响。
- 页面明确注明：通过测试不等于 PostgreSQL SQL 查询已经通过；真实数据库测试需要 Neon 项目连接信息。

## 验收标准

- 腾讯云链接可在普通浏览器和微信中打开。
- 页面无需登录即可自动完成测试。
- 单个目标失败不会阻止其他测试完成。
- 用户可以复制包含各目标状态和耗时的纯文本结果。
- 塔罗主站现有文件和路径保持不变。
