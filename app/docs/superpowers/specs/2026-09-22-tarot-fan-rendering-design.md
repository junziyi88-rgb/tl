# 塔罗扇形选牌渲染与边界回弹设计

## 目标

只重构在线选牌阶段的牌阵渲染与边界反馈：消除拖动时的掉帧、卡牌乱飞、牌背空白或延迟显示，并让牌堆拉到左右端点时具有更明显但可控的弹性。抽牌顺序、点击选牌、牌位数量、文案、视觉主题和后续流程保持不变。

## 渲染架构

- 连续中心位置、速度和动画状态保存在 ref 中，Pointer Events 与滚轮事件不再逐事件触发 React 状态更新。
- 拖动、惯性和回弹由同一个 `requestAnimationFrame` 循环驱动，每个屏幕帧最多写入一次卡牌 transform。
- 扇形使用固定数量的稳定 DOM 节点。节点按槽位复用，仅在整张牌跨过缓冲区边界时更新所代表的牌，不随小数中心位置频繁挂载和卸载。
- React 状态只记录具有业务含义的结果：最终吸附中心、已选牌和现有流程状态。动画过程不经过 React 重排。
- 层级根据卡牌到视觉中心的距离稳定计算，避免滑动时突然换层或互相穿插。

## 牌背绘制

- 牌背先预加载并完成解码，再显示可交互牌阵；失败时保留现有深色占位底色。
- 每张牌使用稳定的真实 `<img>` 图片层，不再把大图作为移动按钮的 CSS 背景反复绘制。
- 生成尺寸适合屏幕显示的 WebP 牌背，并保留原始 JPEG 作为回退。
- 拖动、惯性和回弹期间降低阴影绘制成本，停稳后恢复现有选中高光和静态阴影。

## 手势、惯性与边界

- 保留整个 `.fan-stage` 可拖、8px 点击/拖动分界、14px/张灵敏度、鼠标拖动、触控板横向滚动和 `Shift + 滚轮`。
- 快速甩动继续最多滑行 12 张，但改为逐帧摩擦减速，不再一次跳到目标后依赖 CSS 长距离补间。
- 牌堆越过首尾时使用非线性阻尼；允许的可见超出距离比当前实现更大，拖得越远阻力越强。
- 松手后以短促、略有回摆的弹簧回到首张或末张位置；回弹过程不触发选牌。
- 键盘左右键仍按整张牌移动，并使用同一套吸附动画。

## 异常与可访问性

- 用户开启“减少动态效果”时，禁用惯性与回摆，只做短距离吸附。
- 页面离开或组件卸载时取消动画帧、图片加载回调和滚轮结束计时器。
- 牌背图片提供空 alt，现有按钮的可访问名称、选中状态和键盘操作保持不变。

## 验收标准

- 持续拖动时，卡牌节点数量稳定，小数位置变化不会引发节点批量挂载/卸载。
- 拖动、惯性和回弹均由逐帧位置更新完成，不再出现一次跳过多张牌的 CSS 补间。
- 牌背在牌阵出现前已加载；正常网络下不出现纯色空白牌，图片失败时仍有明确占位。
- 左右端点可明显拉出，并在松手后顺滑回到合法位置；不会越界停留或误触选牌。
- 手机触摸、电脑鼠标、触控板和键盘继续可用，现有选牌及后续流程不变。
- 单元测试、TypeScript 检查、生产构建和浏览器交互验证通过后，再发布至现有腾讯云静态网址。
