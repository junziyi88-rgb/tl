# 塔罗扇形选牌惯性与桌面拖动设计

## 目标

在不改变牌阵、抽牌结果、选牌顺序、页面文案和后续流程的前提下，让扇形牌堆在手机与电脑上都能从整个牌桌区域拖动，并通过速度投射产生自然惯性。

## 交互规则

- 拖动入口从单张牌按钮移到整个 `.fan-stage`。
- 鼠标左键、触摸和触控笔统一使用 Pointer Events；非鼠标左键不启动拖动。
- 水平移动超过 8px 后视为拖动，并阻止本次手势之后的选牌点击。
- 灵敏度从 16px/张提高到 14px/张。
- 保存最近 100ms 的横向指针样本并计算速度。
- 速度低于 0.25px/ms 时只吸附到最近牌位；达到阈值时额外滑行 4–12 张，绝不超过 12 张。
- 惯性目标始终限制在 0–77；边缘拖动继续使用现有弹性，松手后回到合法牌位。
- 触控板水平滚动和 `Shift + 滚轮` 控制牌堆；普通纵向滚轮继续滚动页面。触控板自带惯性不再叠加第二层速度投射，停止滚动后仅吸附。

## 实现边界

- `lib/fan.ts` 提供灵敏度、阈值、速度计算、惯性目标和滚轮轴选择的纯函数。
- `TarotFan` 只负责采样 Pointer Events、把状态传给纯函数、设置拖动/吸附状态。
- 继续使用现有 CSS transform 和 transition，不增加动画依赖。
- 选牌按钮的键盘方向键、点击选牌、选中样式和无障碍标签保持不变。

## 验收标准

- 从牌背或扇形区域空白处按住拖动均能移动牌堆。
- 7px 位移仍可点击，8px 以上不会误选。
- 14px 水平拖动对应约一张牌。
- 慢拖松手就近吸附；快甩继续 4–12 张；边界不会越过首尾。
- 电脑鼠标拖动、触控板横向滚动、`Shift + 滚轮` 均可使用。
- 全量测试、TypeScript 检查和腾讯云生产构建通过。
